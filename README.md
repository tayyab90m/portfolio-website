# Saeed Portfolio

Animated Next.js portfolio for Saeed, a QA Engineer offering manual testing,
automation testing, QA strategy, defect reporting, and release validation
services.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Pages

- Landing page
- About me
- Projects
- Experience
- QA services
- Contact

## Theme

The light and dark theme colors are defined with CSS variables in
`src/app/globals.css`.
